How this was built

A postgraduate 3D Applications project (MSc Advanced Computer Science, University of Sussex), rebuilt here as a portfolio piece.

Real-time WebGL rendering

Models are rendered live in the browser with X3DOM — a declarative X3D/HTML5 layer over WebGL, no plugin or engine install required.

Custom-modeled assets

Each bottle was hand-modeled and textured in Blender and Cinema 4D, then exported to the X3D format for web delivery.

Interactive controls

Orbit, zoom and toggle animation on every model using X3DOM's built-in navigation and scripted ROUTE-driven rotation.

Deployed as a static site

Pure HTML/CSS/JS with no build step, deployed straight to GitHub Pages for a fast, dependency-free demo.

Pick a bottle to explore

Each page has its own free-orbit viewer, animation toggle and product details.
